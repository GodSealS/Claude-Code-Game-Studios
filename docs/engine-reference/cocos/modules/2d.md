# Cocos Creator — 2D Rendering Module

Last verified: 2026-05-08

## Core Types

| Type | Purpose |
|------|---------|
| `Sprite` | 2D image rendering (simple, sliced, tiled, filled modes) |
| `Label` | Text rendering (system font, BMFont, TTF) |
| `Mask` | Clipping/masking children nodes (RECT, ELLIPSE, IMAGE_STENCIL) |
| `Graphics` | 2D vector drawing (line, arc, rect, path) |
| `Sorting2D` | 2D z-order control (3.8.7+) |
| `SpriteFrame` | Individual frame from a sprite sheet or texture |
| `Texture2D` | 2D texture resource |

## Common Operations

```typescript
import { Sprite, SpriteFrame, Label, Mask, Graphics, Color } from 'cc';

// Sprite: change image
const sprite = this.node.getComponent(Sprite)!;
sprite.spriteFrame = newSpriteFrame;
sprite.type = Sprite.Type.SLICED; // SIMPLE, SLICED, TILED, FILLED
sprite.sizeMode = Sprite.SizeMode.CUSTOM; // CUSTOM, TRIMMED, RAW

// Label: text rendering
const label = this.node.getComponent(Label)!;
label.string = "Hello World";
label.fontSize = 24;
label.lineHeight = 32;
label.overflow = Label.Overflow.SHRINK; // CLAMP, SHRINK, RESIZE_HEIGHT

// Mask: clipping
const mask = this.node.addComponent(Mask);
mask.type = Mask.Type.RECT; // RECT, ELLIPSE, IMAGE_STENCIL

// Graphics: vector drawing
const g = this.node.addComponent(Graphics);
g.lineWidth = 2;
g.strokeColor = Color.RED;
g.fillColor = Color.BLUE;
g.circle(0, 0, 50);
g.fill();
g.stroke();
```

## Sprite Animation (SpriteSheet)

```typescript
import { Sprite, SpriteFrame, Animation } from 'cc';

// Play sprite sheet animation programmatically
class SpriteAnimController extends Component {
    @property({ type: [SpriteFrame] })
    frames: SpriteFrame[] = [];

    private _sprite: Sprite = null!;
    private _index = 0;
    private _timer = 0;

    onLoad() {
        this._sprite = this.getComponent(Sprite)!;
    }

    update(dt: number) {
        this._timer += dt;
        if (this._timer >= 0.1) { // 10 FPS
            this._timer = 0;
            this._index = (this._index + 1) % this.frames.length;
            this._sprite.spriteFrame = this.frames[this._index];
        }
    }
}
```

## Performance Optimization

- Use sprite atlases (TexturePacker, auto-atlas in Cocos Creator)
- Prefer SLICED or SIMPLE over FILLED for static UI
- Use BitmapFont for static text; system font for dynamic text
- Combine multiple Graphics draw calls into one component
- Minimize Mask usage due to stencil buffer overhead
- Use `Sorting2D` (3.8.7+) instead of overlapping canvas for z-ordering
- Enable batching: group sprites using the same atlas together

## Pitfalls

- WRONG: Updating `Label.string` every frame
- RIGHT: Only update when value changes; cache string values
- WRONG: Using raw textures without atlas for UI
- RIGHT: Always pack UI sprites into atlases
- WRONG: Creating new `Graphics` components per shape
- RIGHT: Draw all shapes in one `Graphics` component per node
- WRONG: Using `Color` constructors in hot paths (allocations)
- RIGHT: Cache `Color` objects; reuse them
