## 知识差距警告

LLM 的训练数据可能仅覆盖 Cocos Creator 至 ~3.6 版本。3.7–3.8 版本引入了模型可能不了解的重大变更，包括：

- 自定义渲染管线（CRP）及后处理框架
- Spine 4.2 运行时集成
- 延迟渲染管线（3.8+）
- GPU 实例化与 GPU-Driven 渲染改进
- Asset Bundle v2 格式变更
- 微信小游戏性能优化

建议任何 Cocos Creator API 调用前先交叉参考本目录。
