# Review Workflow / 审查工作流

1. Code changes require review by the relevant department lead agent / 代码更改需要相关部门负责人代理审查
2. Design changes require sign-off from `game-designer` and `creative-director` / 设计更改需要 `game-designer` 和 `creative-director` 签字
3. Architecture changes require sign-off from `technical-director` / 架构更改需要 `technical-director` 签字
4. Cross-domain changes require sign-off from `producer` / 跨领域更改需要 `producer` 签字
