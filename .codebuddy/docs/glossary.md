## 翻译规范 / Translation Conventions

### 格式规则

1. **标题双语**：`## English Title / 中文标题`
2. **翻译块**：`> **中文翻译**：翻译内容`
3. **行内注释**：`# English comment / 中文注释`
4. **YAML description**：`"English description / 中文描述"`
5. **术语首次出现**：使用"中文 (English)"格式

### 翻译原则

1. **保留原文**：英文原文始终完整保留，中文作为补充
2. **术语统一**：所有翻译必须参照本术语表
3. **技术术语保留**：变量名、函数名、文件路径、正则表达式绝对不翻译
4. **代码块不翻译**：代码示例中的注释可以双语化，代码本身不翻译
5. **YAML Frontmatter 不翻译**：name、paths 等配置字段保持英文
6. **机翻审校**：机器翻译内容需人工审校，特别是：
   - "精益" → "精简"（lean mode）
   - "独奏" → "单人"（solo mode）
   - "汇入/汇出" → 保留，但加注英文 (faucet/sink)
   - "视觉锚点" → "视觉标识锚点"（Visual Identity Anchor）
